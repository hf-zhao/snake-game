# 贪吃蛇游戏

一个有趣的网页版贪吃蛇游戏，具有以下特点：

- 多种水果食物（苹果、香蕉、橘子、葡萄、西瓜、草莓）
- 漂亮的视觉效果和动画
- 不同水果有不同的分数
- 游戏难度随分数提升
- 精美的游戏结束界面

## 如何游玩

1. 使用键盘方向键控制蛇的移动
2. 吃到不同的水果可以得到不同的分数：
   - 苹果：10分
   - 香蕉：15分
   - 橘子：20分
   - 葡萄：25分
   - 西瓜：30分
   - 草莓：35分
3. 注意不要撞到墙壁或自己的身体
4. 分数越高，移动速度越快

## 玩法技巧

1. 开始时可以先追求低分水果，熟悉操作
2. 随着长度增加，要更加小心地规划路线
3. 高分水果出现时要权衡是否值得冒险
